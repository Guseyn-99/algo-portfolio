## Методика исследования

- Разработка восьми вариантов решения каждой задачи.
- Проверка корректности алгоритмов на тестовых данных.
- Измерение времени через `time.perf_counter()`.
- Медиана пяти замеров времени.
- Измерение пиковой дополнительной памяти через `tracemalloc`.
- Подсчёт сравнений и вычислений хешей.
- Ограничение длительности экспериментов через `multiprocessing` в задачах 02–08.
- Анализ временной и пространственной сложности.
- Проверка изменения исходных данных.
- Выбор алгоритмов с учётом требований заказчиков.

## Запуск

Из директории соответствующей задачи:

```powershell
uv run --python 3.12 --no-project python solutions.py
uv run --python 3.12 --no-project python benchmark.py
```

## Общий вывод

Выбор алгоритма зависит от размера входных данных, ограничений памяти, требуемой скорости и особенностей поставленной задачи.

Одинаковая асимптотическая сложность не гарантирует одинаковую производительность. Экспериментальные замеры позволяют оценить эффективность различных реализаций и обосновать выбор решения для конкретных условий.
