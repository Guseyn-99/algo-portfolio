## Методика исследования

- Восемь вариантов решения каждой задачи.
- Проверка корректности алгоритмов.
- Измерение времени через `time.perf_counter()`.
- Медиана пяти замеров времени.
- Измерение пиковой памяти через `tracemalloc`.
- Подсчёт сравнений и вычислений хешей.
- Ограничение длительности экспериментов через `multiprocessing` в задачах 02 и 03.
- Выбор алгоритмов с учётом требований заказчиков.
