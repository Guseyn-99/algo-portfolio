## 1. Условие задачи

Найти минимальное число в непустом списке целых чисел.

**Пример:** `[8, 3, 11, -2, 5] → -2`.

## 2. Методика измерений

Для эксперимента использованы три набора данных:

- 1 000 случайных чисел;
- 100 000 случайных чисел;
- 100 000 чисел с минимальным элементом в конце.

Время измерялось через `time.perf_counter()`. Каждый алгоритм запускался пять раз, после чего вычислялась медиана.

Пиковая дополнительная память измерялась через `tracemalloc`. Количество сравнений определялось с помощью класса `CountedNumber`.

Копирование входных данных выполнялось до начала замеров.

## 6. Выбор решения для заказчиков

### Сценарий 1. Большой вход, память ограничена

**Условия:** n = 10 000 000, дополнительная память не более 8 МБ.

**Подходит — `min()`** — алгоритм имеет линейную временную сложность O(n), использует постоянную дополнительную память O(1) и не изменяет исходный список.

По результатам эксперимента это наиболее быстрый вариант. Для n = 10 000 000 выбор основан на асимптотике и результатах меньших замеров, а не на прямом эксперименте.

### Сценарий 2. Малый вход, нужен быстрый ответ

**Условия:** n = 100, один запрос.

**Подходит — `min()`** — встроенная функция показала наименьшее время выполнения на малом тестовом наборе и не требует дополнительных структур данных.

Выбор для n = 100 сделан на основе результатов замеров при n = 1 000.

## 7. Вывод

В ходе практической работы были реализованы и исследованы восемь способов поиска минимального элемента.

Наиболее эффективным решением оказалась встроенная функция `min()`. Она выполняет n − 1 сравнений, имеет временную сложность O(n) и использует O(1) дополнительной памяти.

Сортировка оказалась менее эффективной, поскольку для поиска одного минимального элемента не требуется упорядочивать весь список.

Рекурсивный алгоритм, несмотря на сложность O(n), показал более длительное время выполнения из-за накладных расходов на вызовы функций.

Эксперимент показал, что одинаковая асимптотическая сложность не всегда означает одинаковую скорость выполнения.
