\# Работа № 3 · Замеры времени и памяти



\*\*Дисциплина:\*\* ОП.04 «Основы алгоритмизации и программирования»  

\*\*Студент:\*\* Гасанов Гусейн  

\*\*Группа:\*\* 11/2-РПО-25/1



\## Что изучалось



Измерение времени выполнения программ и использования памяти.

Сравнение практических результатов с оценками сложности O(1), O(n)

и O(n²), влияние размера входных данных на производительность.



\## Задание



Запустить предложенные примеры Python, зафиксировать результаты

на скриншотах и сформулировать выводы для каждого эксперимента.



В отчёте представлены 10 экспериментов: повторные замеры,

поиск элементов, обработка пар, суммирование, сравнение list и set,

использование памяти и поиск дубликатов.



\## Какие навыки закрепляет работа



\- Измерение времени выполнения и пикового использования памяти.

\- Сравнение алгоритмов на разных объёмах данных.

\- Использование медианы для оценки повторных замеров.

\- Анализ компромисса между скоростью и расходом памяти.

\- Оформление результатов экспериментов и выводов.
